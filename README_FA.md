# هم‌پیوند — نسخهٔ اولیه (MVP)

**هم‌پیوند** یک بازار برای اتصال نیروی انسانی، مهارت، ملک، تجهیزات، تأمین کالا و سرمایه به آگهی‌ها و پروژه‌های کسب‌وکار است.

## فناوری‌ها

- فرانت‌اند: React + Vite + Tailwind CSS v4 + Lucide
- نقشه: React Leaflet و کاشی‌های OpenStreetMap
- بک‌اند: Django 6.1 + Django REST Framework
- احراز هویت: شمارهٔ همراه و OTP با توکن API؛ کد آزمایشی در حالت توسعه
- پایگاه دادهٔ محلی: SQLite؛ تنظیمات نمونه برای PostgreSQL موجود است
- پنل مدیریت: Django Admin با بخش‌های فارسی
- رابط: فارسی، راست‌چین و با تاریخ محلی شمسی در بخش‌های نمایشی

## اجرای بک‌اند در ویندوز (PowerShell)

```powershell
cd backend
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
python manage.py makemigrations marketplace
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

فرمان `createsuperuser` شمارهٔ تلفن و رمز عبور می‌خواهد. آدرس پنل مدیریت: `http://127.0.0.1:8000/admin/`.

اگر می‌خواهی PostgreSQL استفاده کنی، متغیرهای `DB_ENGINE`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `DB_HOST` و `DB_PORT` را در `backend/.env` تنظیم کن و سپس migrationها را اجرا کن.

## اجرای فرانت‌اند

در ترمینال دوم:

```powershell
cd frontend
npm install
Copy-Item .env.example .env.local
npm run dev
```

سپس `http://localhost:5173` را باز کن. اگر بک‌اند روی آدرس دیگری اجرا می‌شود، `VITE_API_BASE_URL` را در `frontend/.env.local` تغییر بده.

### حالت پیش‌نمایش

- در `DEBUG=True`، درخواست OTP کد `123456` را برمی‌گرداند. این حالت فقط برای توسعه است.
- اگر بک‌اند اجرا نباشد، رابط کاربری به حالت پیش‌نمایش محلی می‌رود؛ آگهی‌ها و پیام‌های نمونه در همان مرورگر شبیه‌سازی می‌شوند و در سرور ذخیره نمی‌شوند.
- `VITE_DEMO_MODE=true` (پیش‌فرض) محتوای نمونه را نشان می‌دهد. برای محیط متصل به داده‌های واقعی، `VITE_DEMO_MODE=false` قرار بده.
- انتخاب موقعیت روی نقشه به اینترنت برای دریافت کاشی‌های OpenStreetMap نیاز دارد.

## APIهای موجود

تمام مسیرها با پیشوند `/api/` هستند.

| مسیر | کاربرد |
|---|---|
| `POST /api/auth/request-otp/` | درخواست کد ورود |
| `POST /api/auth/verify-otp/` | بررسی OTP و دریافت توکن |
| `GET/PATCH /api/auth/me/` | مشاهده یا ویرایش پروفایل خود |
| `POST /api/auth/logout/` | باطل‌کردن توکن ورود |
| `GET /api/users/{id}/contact/?listing={id}` | مشاهدهٔ راه‌های تماس مجاز در زمینهٔ یک آگهی |
| `GET /api/users/{id}/contact/?project={id}` | مشاهدهٔ راه‌های تماس مجاز در زمینهٔ پروژه |
| `/api/listings/` | جست‌وجو و مدیریت آگهی‌های مستقل |
| `/api/listings/?mine=1` | آگهی‌های مالک واردشده |
| `/api/listings/{id}/invite/` | دعوت کاربر به آگهی خصوصی با `user_code` |
| `/api/listings/{id}/revoke_invite/` | لغو دسترسی دعوت‌شده |
| `/api/projects/` | جست‌وجو و مدیریت پروژه‌ها |
| `/api/projects/?mine=1` | پروژه‌های سازندهٔ واردشده |
| `/api/projects/{id}/invite/` | افزودن عضو پروژه با شناسهٔ کاربری |
| `/api/needs/` | نیازهای پروژه؛ برای ساخت، شناسهٔ `project` لازم است |
| `/api/applications/` | ارسال و مشاهدهٔ درخواست‌ها |
| `/api/applications/{id}/transition/` | تغییر مرحله با `action`: `negotiate`, `shortlist`, `reject`, `archive`, `withdraw`, `confirm` |
| `/api/conversations/` | ایجاد و مشاهدهٔ گفت‌وگوها و روم‌های پروژه |
| `/api/messages/` | پیام‌های داخل گفتگو |
| `/api/calendar-events/` | رویدادهای تقویم |
| `/api/contact-grants/` | مشاهده و ایجاد مجوزهای محدود اطلاعات تماس |
| `/api/contact-grants/{id}/revoke/` | لغو مجوز اطلاعات تماس |

برای مسیرهای محافظت‌شده، هدر `Authorization: Token <token>` لازم است.

## مدل دادهٔ کلیدی

- **کاربر**: شمارهٔ تأییدشده، شناسهٔ عمومی مثل `HP-AB12CD3`، تنظیمات راه‌های تماس و نشانه‌های تأیید.
- **آگهی**: استخدام، ملک/تجهیزات، مهارت/خدمت، تأمین کالا یا سرمایه؛ با موقعیت، بازهٔ زمانی، سطح دسترسی و ویژگی‌های تخصصی.
- **پروژه**: می‌تواند عمومی، مخفی با لینک، یا خصوصی/دعوت‌محور باشد.
- **نیاز پروژه**: مقدار و واحد، بودجه، زمان و روش تأمین تک‌تأمین‌کننده‌ای یا چندتأمین‌کننده‌ای.
- **درخواست**: برای آگهی مستقل یا یک نیاز پروژه؛ مراحل جدید، مذاکره، انتخاب اولیه، توافق نهایی، رد و انصراف.
- **گفت‌وگو و پیام**: هر گفت‌وگو به درخواست یا پروژه متصل و دسترسی آن محدود به شرکت‌کنندگان است.
- **مجوز اطلاعات تماس**: قابلیت نگهداری مجوزهای دسترسی/لغو برای شماره، ایمیل و پیوندها.
- **جایگاه تبلیغاتی و تبلیغ**: قابل مدیریت در ادمین، با شمارندهٔ نمایش و کلیک.

## برند و دارایی‌ها

- `frontend/public/logo.svg` و `frontend/public/favicon.svg`: نشان اولیهٔ هندسی هم‌پیوند.
- `docs/brand-guide.md`: رنگ‌ها، تایپوگرافی و اصول استفاده از هویت بصری.
- دامنه و ثبت علامت تجاری «هم‌پیوند» هنوز از نظر در دسترس‌بودن/حقوقی بررسی نشده‌اند.

## وضعیت تکمیل — شفاف و مهم

این خروجی یک **MVP اولیه برای شروع توسعه** است، نه نسخهٔ آمادهٔ انتشار عمومی. نحو فایل‌های JSX و پایتون بررسی شده؛ با این حال وابستگی‌های npm در محیط ساخت نصب نشدند و build کامل فرانت‌اند یا آزمون اجرایی یکپارچه تأیید نشده است. رابط کاربری، مسیرهای اصلی و مدل‌های بک‌اند ساخته شده‌اند؛ اما پیش از راه‌اندازی عمومی باید این موارد تکمیل و تست شوند:

1. **SMS.ir:** اتصال ارسال واقعی پیامک در فایل `backend/marketplace/views.py` عمداً fail-closed است. API key، شناسهٔ قالب و نمونهٔ درخواست رسمی متناسب با حساب SMS.ir لازم است و تا زمان تنظیم آن، در محیط غیرتوسعه ورود SMS کار نمی‌کند.
2. **آزمون خودکار:** migrationها را ایجاد کن و تست‌های API/دسترسی، درخواست هم‌زمان و قفل ظرفیت را اضافه و اجرا کن.
3. **پیام‌رسانی لحظه‌ای:** رابط پیام یک نمونهٔ تعاملی است؛ برای چندکاربره و زنده‌شدن گفتگو باید Django Channels/WebSocket یا سرویس realtime اضافه شود.
4. **نقشه و نشانی:** نمایش نقشه متصل به OpenStreetMap است؛ reverse geocoding، سیاست نگهداری مختصات و آدرس دقیق هنوز نیاز به تصمیم و پیاده‌سازی دارد.
5. **دسترسی تماس:** مدل و مسیرهای پایهٔ اعطا/لغو مجوز در بک‌اند موجود است؛ اتصال کامل تنظیمات تماس رابط به این مسیرها و تست همهٔ حالت‌های دسترسی هنوز لازم است.
6. **دولت من:** اتصال رسمی و دسترسی API باید مستقیماً از مرجع مربوط تأیید شود؛ در نسخهٔ فعلی پیاده‌سازی نشده است.
7. **پرداخت/قرارداد:** در این نسخه پول بین طرفین جابه‌جا نمی‌شود و سامانه تضمین‌کنندهٔ قرارداد یا تسویه نیست.
8. **آمادگی انتشار:** `DEBUG=False`, کلید محرمانهٔ قوی، HTTPS، محدودسازی درخواست‌های OTP در سطح IP/شماره، سیاست نگهداری داده، بکاپ، ثبت رویدادهای امنیتی، تست بار و بررسی امنیتی لازم‌اند.

**هرگز `DEBUG=True` را روی سرور عمومی فعال نکن.** کد آزمایشی فقط در توسعه قابل نمایش است.
